Programme Ambassadeur

Gagnez à chaque événement.

Memora récompense les organisateurs qui font vivre la plateforme. Le programme est sur sélection : une fois votre compte reconnu comme ambassadeur, chaque événement payé vous rapporte une commission qui grandit avec votre activité — et vous touchez aussi sur les événements des organisateurs que vous amenez.

Parrainage

Amenez d'autres organisateurs, gagnez avec eux.

Une fois ambassadeur, partagez votre lien de parrainage — ou votre code — depuis votre tableau de bord. Dès qu'un organisateur que vous avez amené vend un événement, Memora vous verse {{ memora_commission_referral }}{% if memora_commission_is_percent %} du prix de la vente{% endif %} — pour chacun de ses événements payés, pas seulement le premier.

  1. Partagez votre lien ou votre code de parrainage.
  2. Ils s'inscrivent et créent leurs événements.
  3. Vous touchez {{ memora_commission_referral }}{% if memora_commission_is_percent %} du prix{% endif %} à chaque événement qu'ils vendent.

Vos versements

Vous demandez, Memora verse.

Vos gains s'accumulent sur votre tableau de bord, où vous suivez leur évolution mois par mois. Dès que votre solde disponible atteint {{ memora_minimum_payout }}, vous demandez un retrait en indiquant vos coordonnées (Mobile Money, virement bancaire ou autre).

  1. Vos commissions s'ajoutent à chaque événement payé.
  2. Vous demandez le versement de votre solde disponible.
  3. Memora verse et vos commissions passent en « payées ».

Une demande à la fois : le montant demandé est réservé jusqu'au versement. Si une demande est refusée, les commissions redeviennent disponibles.
